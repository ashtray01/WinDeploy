# WinDeploy Legacy (Windows 7 SP1)

`legacy/` — отдельный Go 1.20-модуль с нативным Win32 GUI на Walk. WebView2, .NET и современные API не используются. Общее ядро подключается через `replace windeploy => ../`.

## Сборка

```powershell
scripts/build-legacy.ps1 -GuiSmoke
```

Скрипт собирает `bin/WinDeploy-Legacy-Windows-x64.exe` и `...-x86.exe` с манифестом Common Controls 6 (встроен в `rsrc_windows_*.syso`), запускает тесты, headless `--selftest` и, с `-GuiSmoke`, создаёт реальное окно и закрывает его через 3 секунды.

Требуется Go 1.20.14 (путь по умолчанию `local/_toolchains/go1.20.14/go/bin/go.exe`). Зависимости: `github.com/lxn/walk` (Win32), `golang.org/x/sys v0.6.0`; модуль фиксирует версии в `go.mod/go.sum`.

## Возможности

- Сводка: компьютер, Windows, архитектура, CPU, RAM, права администратора, статус лицензирования (read-only).
- Программы: совместимый с текущей Windows каталог, отметки, установка выбранных через общий Package Manager (загрузка, SHA-256, Authenticode, silent install, проверка), отмена, обновление статусов. Несовместимые и уже установленные программы заблокированы.
- Сеть: read-only диагностика (DHCP, шлюзы, DNS localhost), подключение UNC-папки с паролем только в памяти и ярлыком на рабочем столе.
- Диагностика Windows Update и статус лицензирования — только чтение.
- Журнал операций.

Изменяющие действия требуют подтверждения и прав администратора; приложение не устанавливает драйверы/принтеры и не меняет настройки Windows в Legacy-версии.

## Проверено

- Go 1.20.14, `GOOS=windows`, amd64 и 386: `go test ./...`, `go vet`, сборка PASS.
- `--selftest` на Windows 11 x64: каталог 12 программ, детекция 7-Zip, совместимость — PASS.
- `--smoke` (реальное окно, auto-close) на Windows 11 x64 и x86 (WOW64): PASS.
- Без манифеста Common Controls Walk падал на `TTM_ADDTOOL`; корректный манифест с `supportedOS` GUID и `rsrc_windows_*.syso` это устранил. Это также нужно для визуальных стилей Win7.

## Не проверено

- Windows 7 SP1 VM (главная цель) и реальные установки/UNC на ней. Текущая Windows 11 не доказывает совместимость с Win7.
- Walk 2021 на Win7 SP1 без обновлений; требуется чистая VM с .NET не требуется, но нужны Common Controls 6 (входят в Win7).
- Реальные установщики, SMB-сервер, права администратора и перезагрузка.
