# WinDeploy — Known Issues (v0.1.0-beta.1)

Beta означает: приложение полезно, но не production-ready. Ниже перечислены
известные ограничения и способы их распознать. Не заявляйте о поддержке
сценария, который здесь отмечен как непроверенный.

| ID | Область | Влияние | Статус / обход |
|---|---|---|---|
| KI-01 | Code signing | EXE не подписан; SmartScreen может предупредить, некоторые политики запретят запуск | Известно. Проверяйте SHA-256 из Release; подпись — POST-BETA |
| KI-02 | Установка ПО | Нет реального clean-install acceptance одного пакета в этой итерации; target-version update может не отличаться от install | BETA BLOCKER B1. Проверять на одноразовой Win11 VM/хосте с разрешения владельца |
| KI-03 | SMB | Подключение с реальным сервером, credentials context и Error 1219 не проходили VM-приёмку | BETA BLOCKER B2. Используйте тестовый сервер, не рабочую учётную запись |
| KI-04 | Reboot continuation | Verify-only после смены boot identity покрыт тестами, но реальный reboot/fast startup не проверен | Не обещать завершение после reboot; pending остаётся pending |
| KI-05 | Драйверы | Установка подписанного INF не прошла VM-проверку; target version/publisher проверяются не полностью | **Экспериментально**. Не использовать на рабочей машине |
| KI-06 | Принтеры | TCP/IP-порт не создаётся автоматически (P1-01); добавление принтера может завершиться ошибкой; реальная печать не проверялась | **Экспериментально**. Добавляйте принтер штатными средствами Windows |
| KI-07 | Browser policies | Read-back есть в коде/тестах, но полная VM-проверка, restore и сосуществование с GPO не закрыты | **Экспериментально** |
| KI-08 | Windows settings | Rename/timezone/power/Explorer имеют preview и часть read-back, но VM/домен/restore не проверены | **Экспериментально**. Rename может потребовать reboot/перелогин |
| KI-09 | Windows 10/LTSC | Нет проверки; API могут отличаться | В beta поддержка **не заявляется**; только Windows 11 x64 |
| KI-10 | Session storage | Owner/ACL проверяются перед изменяющим resume, но это не аутентификация файла и не защита от same-user/administrator tampering | Не считать каталог сессий доверенным без Windows ACL; elevated resume не автоматизируется |
| KI-11 | Cancellation | Отмена завершает прямой процесс; дочерние процессы установщика могут остаться | Не обещать rollback; проверяйте Диспетчер задач/журнал |
| KI-12 | OneDrive/antivirus | Внешний процесс может держать state-файл; добавлены ограниченные повторы замены | При постоянной ошибке используйте локальный каталог и проверьте антивирус |
| KI-13 | WebView2 | Evergreen Runtime обязателен и не поставляется. Основной cache может быть недоступен из-за ACL/песочницы; приложение предлагает admin relaunch и умеет работать с резервным/портативным каталогом | Установите WebView2 Runtime. В резервном режиме смотрите путь в `startup.log`; данные основного профиля не удаляются |
| KI-14 | Package catalog | Версии и URL закреплены; upstream может удалить/изменить файл | SHA-256 не совпадёт — установка остановится; обновление каталога — POST-BETA |
| KI-15 | License/repository | Лицензия не выбрана, публичный URL/remote не зафиксированы | Публичное открытие исходников заблокировано до решения владельца |

## Что не является известным дефектом

- Отсутствие Windows 7: Legacy FROZEN и не входит в beta.
- Отключённая кнопка настроек в Shell: возможность явно помечена как недоступная.
- Экспериментальные страницы с предупреждением: это осознанная граница beta, а не
  скрытая функция.
- Отказ user-scoped операции при другом SID/unknown shell: это fail-closed
  security gate, а не ошибка совместимости.

## Как сообщать

Используйте GitHub Bug report. Приложите версию, Windows build, шаги, ожидаемое и
фактическое поведение, обезличенный фрагмент `startup.log`/отчёта. Не прикладывайте
пароли, токены, приватные адреса, имена пользователей и корпоративные пути.
