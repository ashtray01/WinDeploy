# Проверка общего ядра Go 1.20

Root go.mod сохраняет `go 1.20`, Wails в его зависимостях отсутствует. Для независимой проверки доступна команда:

```powershell
.\scripts\test-core.ps1 -Go .\local\toolchains\go1.20.14\go\bin\go.exe
```

Скрипт печатает фактическую версию компилятора, запускает test/vet/build корневого модуля на windows/amd64 и windows/386 и восстанавливает переменные окружения. Modern является вложенным модулем и намеренно не входит в эту проверку.

Официальный Go 1.20.14 загружается только в local/toolchains; системный Go/PATH не меняются. Первая загрузка `https://go.dev/dl/go1.20.14.windows-amd64.zip` оборвалась на 67,920,092 из 114,273,182 bytes, checksum не прошёл. Повтор через dl.google.com с identity encoding выполняется отдельно. Непроверенный архив не распаковывается и не запускается. Фактический финальный результат указывается в HANDOFF/отчёте; сборка Go 1.26 не считается заменой этой проверки.

Даже успешные Go 1.20 test/build на текущей Windows не подтверждают запуск Win7 SP1 — нужна соответствующая VM.
