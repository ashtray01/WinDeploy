# WinDeploy v0.1.0-beta.1 — Public Beta

**Public Beta — software under active development.** Это не stable и не
production-ready релиз. Основной сценарий проверялся на Windows 11 x64; Windows
10/LTSC и изменяющие VM-сценарии остаются ограничениями.

## Что работает

- Modern Windows GUI: Inventory, профили, каталог программ, диагностика сети,
  сетевые папки, журнал, выполнение и отчёты.
- Просмотр компьютера и установленных программ без изменения системы.
- Каталог из 12 закреплённых программ с detection, выбором, подтверждением,
  проверкой SHA-256/подписи и фоновая установка.
- Предварительный план профиля до запуска; зависимости, DAG и проверка требований
  ОС. Экран выполнения требует построить план и подтвердить запуск.
- Живой прогресс, отмена, честные успешные/неуспешные/пропущенные результаты,
  warnings о неподтверждённых эффектах.
- HTML/JSON-отчёт без параметров задач и паролей.
- Network diagnostics read-only: DNS/DHCP/gateway/TCP/ICMP/HTTP/SMB.
- Session resume с bounded parsing, owner/ACL trust и fail-closed проверкой boot
  evidence; без ложного `Success` после reboot.
- Modern EXE не требует Go/Node.js на целевой машине. Нужен Microsoft Edge
  WebView2 Runtime.
- Startup log пишется в файл даже в GUI-процессе без валидного stderr; путь
  указан в диалоге ошибки запуска.
- Если каталог WebView2 недоступен, приложение проверяет безопасный резервный
  каталог и предлагает «Продолжить с резервным каталогом» или «Выход» без UAC;
  существующие данные не удаляются. Повторный запуск использует тот же каталог.

## Поддерживаемая ОС

- **Windows 11 x64** — основная и проверенная платформа beta.
- Windows 10 x64 / LTSC — код может работать, но **не проверялся**; поддержка не
  заявляется.
- Windows 7 / Legacy — **FROZEN**, в beta-артефакт не входит.

## Установка

1. Скачайте `WinDeploy-Windows-x64.exe` из Assets релиза.
2. Проверьте SHA-256 по `SHA256SUMS.txt`.
3. Запустите EXE. Установка не требуется; приложение работает из своей папки.
4. При первом запуске выполняется read-only Inventory. Изменяющие операции
   требуют явного подтверждения и обычно прав администратора.
5. Для SMB-подключения нужен доступный сервер и учётная запись. Пароль
   передаётся Windows Credential Manager; не публикуйте его в Issue.

EXE **не подписан** сертификатом code signing. Windows SmartScreen может
показать предупреждение. Сверяйте хеш из GitHub Release; не запускайте файл из
неизвестного источника.

## Безопасность

- Пользовательские изменения требуют совпадения SID процесса и владельца
  интерактивного shell; unknown/mismatch fail closed.
- Session-файлы ограничены по размеру, строго декодируются и проверяются по ID,
  owner и write-ACE перед изменяющим resume.
- Установщик принимается только при совпадении закреплённого SHA-256 и/или
  доверенной Authenticode-подписи; обязательная подпись при её отсутствии
  отклоняется.
- Отчёты не содержат parameters задач; пароли SMB не пишутся в отчёт.
- Нет автоматического повышения прав, elevated worker или скрытых изменений
  системы.
- Production EXE не регистрирует `--smoke-port` и не включает WebView2 DevTools;
  remote debugging доступен только в непакетируемой diagnostic-сборке с тегом
  `smoke`.
- Known Issues и residual risks: `docs/KNOWN_ISSUES.md`, `SECURITY.md`.

## Известные ограничения

- Реальная установка одного безопасного пакета, SMB-сервер и reboot acceptance
  ещё не закрыты на чистой VM. Не считать unit-тесты доказательством E2E.
- Драйверы, добавление принтеров, политики браузеров и изменение параметров
  Windows — **экспериментальные**. Для них нет VM-приёмки; добавление TCP/IP
  принтера может не создать порт.
- Отмена установщика не гарантирует остановку дочерних процессов.
- OneDrive/antivirus может кратковременно блокировать файловые операции; добавлены
  ограниченные повторы, но это не устраняет все внешние блокировки.
- Session owner/ACL — не аутентификация автора файла и не защита от
  same-user/administrator tampering.
- Нет автообновления. Версии каталога закреплены и могут устареть.
- Windows 10/LTSC не проверялись. Windows 7 не поддерживается.
